# Digital Fighters (PC)

Protótipo de luta 2D feito com Godot 4. O Herói Vermelho enfrenta o Herói Azul em partidas de melhor de três rounds.

## Executar

Na raiz do repositório: `npm run play:pc`

Para abrir o editor: `npm run editor:pc`

## Controles

- P1: `A/D` move, `W` pula, `F` golpe leve, `G` golpe forte, `H` especial e `R` defende.
- `F2` alterna entre adversário controlado pela CPU e dois jogadores.
- P2: setas movem, `J/K/L` atacam e `I` defende.
